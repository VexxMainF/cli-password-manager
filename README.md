# 🔥 CLI Password Manager (AES-Encryption)

Простой и надежный консольный менеджер паролей на Python с использованием продвинутого шифрования **AES**. Отличный инструмент для безопасного хранения учетных данных локально на вашем компьютере.

> 📌 **Важное примечание:** Программа работает исключительно через **терминал (командную строку)** и **не имеет графического интерфейса (GUI)**. Ввод мастер-пароля при авторизации происходит «вслепую» (символы не отображаются на экране ради безопасности).

## ✨ Особенности
* 🔒 **Надежное шифрование**: Все пароли шифруются с помощью библиотеки `cryptography` (алгоритм AES).
* 🛡️ **Безопасный вход**: Доступ к базе защищен Мастер-Паролем, который хешируется через SHA-256.
* 👁️ **Скрытый ввод**: При вводе паролей в консоли они скрыты от посторонних глаз.

## 🚀 Инструкция по запуску

### 1. Клонируйте репозиторий или скачайте файлы
Убедитесь, что файлы `pm.py` и `requirements.txt` находятся в одной папке.

### 2. Установите зависимости
Для работы шифрования необходимо установить библиотеку `cryptography`. Выполните команду в терминале:
```bash
pip install -r requirements.txt
```

### 3. Запустите программу
```bash
python pm.py
```

## ⚠️ Важное примечание по безопасности
При первом запуске программа создаст файлы `secret.key` (ключ шифрования) и `passwords.json` (зашифрованная база). 
**Никогда не загружайте эти файлы на GitHub!** Обязательно добавьте их в ваш `.gitignore`.
